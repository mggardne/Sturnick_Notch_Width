# Sturnick_Notch_Width
Dan Sturnick's original Matlab files for characterizing knee notch width.

These files are associated with Dan Sturnick's original Matlab files for characterizing knee notch width.  These files are here as a backup.

See Whitney_AJSM_2014_FemoralNotch_ACL_Risks.pdf for a description of the methodology and original results.  See M-file header comments for more details about individual files.

The CSV file's (generated from an OsiriX segmentation) name starts with the subject number (3 numerals), R or L for right or left leg, COROB for coronal oblique view, RH for ridge height, and the segmenter's two letter initials.

Note:  The original CSV files used just RIDGE instead of RH in the file names.

See GitHub repository Notch_Width for updated files characterizing notch width and volume.
